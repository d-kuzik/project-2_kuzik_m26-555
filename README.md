Primitive DB

Primitive DB — учебная консольная база данных на Python. Проект реализует создание и удаление таблиц, добавление, выборку, изменение и удаление записей. Данные и метаданные сохраняются в JSON-файлах.

Возможности

создание таблиц с типами int, str, bool;

автоматическое добавление поля ID;

просмотр списка таблиц;

удаление таблиц с подтверждением;

добавление записей;

выборка всех записей или записей по условию;

изменение записей;

удаление записей с подтверждением;

просмотр информации о таблице;

сохранение данных между запусками программы;

обработка ошибок базы данных;

измерение времени выполнения операций;

кэширование результатов выборки.

Установка

Для запуска проекта требуется Python 3.12+ и uv.

Установить зависимости:

uv sync

Запуск

Запустить программу:

uv run project

После запуска появится консоль базы данных.

Основные команды

Создание таблицы:

create_table users name:str age:int is_active:bool

Просмотр таблиц:

list_tables

Добавление записи:

insert into users values (Ivan, 25, true)

Выборка всех записей:

select from users

Выборка по условию:

select from users where name = Ivan

Изменение записи:

update users set age = 26 where name = Ivan

Удаление записи:

delete users where name = Ivan

Удаление таблицы:

drop_table users

Информация о таблице:

info users

Справка:

help

Выход:

exit

Структура проекта

src/primitive_db/
├── main.py
├── engine.py
├── core.py
├── utils.py
├── parser.py
├── decorators.py
└── constants.py

Назначение модулей

main.py — точка входа в приложение.

engine.py — консольный цикл и обработка команд.

core.py — основная логика работы с базой данных.

utils.py — загрузка и сохранение JSON-файлов.

parser.py — разбор аргументов и условий команд.

decorators.py — обработка ошибок, подтверждение действий, замер времени и кэширование.

constants.py — константы проекта.

Хранение данных

Метаданные таблиц сохраняются в:

db_meta.json

Данные отдельных таблиц сохраняются в каталоге:

data/

Например:

data/users.json

Проверка проекта

Проверка Ruff:

uv run ruff check .

Сборка пакета:

uv build

Проверка собранных пакетов:

uvx twine check dist/*
